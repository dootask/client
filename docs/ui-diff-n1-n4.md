# N1–N4 与旧版的界面差异清单（2026-11-11）

对照基准见 ui-spec 第 1 节：Web/桌面照旧 Vue 前端，App 照 resources/app 实际界面（main 9ebabf7 正式包）。
数据来源：机柜 qoder 逐屏对比，`~/qa/cmp-web-wide/`（1280×860）、`~/qa/cmp-web-narrow/`（390×844）、`~/qa/cmp-app/`（安卓 1080×2400），每项有旧/新成对截图和 DOM / uiautomator 实测值。

归类：
- **漏了**：旧版有、我没做
- **我改的**：旧版有、我做成了别的样子
- **我加的**：旧版没有、我自己加的
- **缺陷**：和旧版无关，本身就是错的

默认处理一律是「照旧版改」。只有「待商量」一列打了 ? 的需要用户拍板，商定后登记到 ui-spec 第 10 节。

端：W = Web 宽屏（桌面），M = Web 窄屏（手机网页），A = App。

## 小结

- App 端会话内（气泡、菜单、回复、编辑、快捷消息）基本一致，差在：列表页、标题下分类行、加号面板、多选栏、转发
- Web 端差得最多：我把 App 的视觉（浅绿气泡、圆角方头像、胶囊筛选、列表式菜单、悬停浮条）用到了网页，网页应照旧 Vue 的样子
- 缺陷 3 个：5.3 Web 表情面板关不掉、5.6 App 加号面板被裁、5.7 单聊 @ 不弹成员
