# 旧版 Web 会话相关页面规格（spec-dialog-pages）

- 站点：`测试服`（旧版前端，Vue 2 + iView + Element-UI），聊天页 `/manage/messenger`
- 登录态：`~/qa/state-old-admin.json`（DooTask，管理员）；用户态 `~/qa/state-old-user.json`（何翔，部分入口用管理员）
- 视口：宽 1280×860；窄 390×844（`isMobile + hasTouch`）
- 浏览器：一律经 `~/qa/browser.mjs` 的 `launch()` 启动（强制 IPv4），未使用安卓模拟器
- 方法：Playwright DOM + `getComputedStyle` 逐部件测量；hover/click 真实交互；截图为元素/视口局部裁切
- box 约定：`(x, y) w×h`，单位 px。未注明时，面板/浮层坐标为视口绝对坐标；列表行、卡片为相对父容器坐标
- 样式缩写：fs=font-size，fw=font-weight，lh=line-height，m=margin，p=padding，bd=border，r=border-radius，bg=background-color，op=opacity
- 颜色统一 hex；`〃` 表示与上一行同部件（另一视口）
- 原始测量：`n6-spec/measure/*.json`；截图：`n6-spec/shots/*.png`
- 测试群：`34200`「n6-spec测试群」（群主 DooTask，成员 何翔、周海源），仅用于改状态操作；未解散/未退出现有群

## 1. 会话信息页（群聊 / 单聊 / 项目群 / 任务群）

### 入口
- 群聊/项目群/任务群：点聊天头部标题（`.dialog-nav` 群名）→ 右侧信息面板；或点头部「···」菜单第 2 项「群组设置」。
- 单聊：点头部标题 → 个人资料卡片（不是信息面板）。**单聊的会话信息侧栏：旧版无。**
- 项目群（26809 点餐系统(Scrum)）、任务群（34192 HalfSheet）面板结构、尺寸与普通群一致；任务群同样显示「添加成员」。

### 呈现方式 / 动画
- 右侧抽屉 `.overlay-body` + `.overlay-content`，从右推入；`transition: all`（computed），实测无独立缓动参数。
- 宽版带遮罩 `rgba(55,55,55,0.6)`；窄版全屏覆盖，无遮罩、无圆角。
