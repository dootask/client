# UI 规范

> 适用于本项目所有页面和公共组件（`src/ui/`）。本文只定设计标准，不定代码结构。
> 第 0–8 节来自 `resources/app` 的 `docs/native-ui-spec.md`，按本项目的决定改过；第 9 节是宽屏和桌面的补充。令牌的代码在 `src/ui/theme/tokens.ts`，两边不一致时先改本文再改代码。
> **2026-11-11 起以旧版为准**（第 0 节第 1 条）：本文第 1–9 节的数值和做法是改规则前定的，按 N1–N4 逐屏对比的结果逐项核对，和旧版不一致又不在第 10 节登记里的，改成旧版的样子。

## 0. 原则

1. **界面照旧版，代码重写**。重写的是代码，不是界面：布局、颜色、字号、间距、图标、菜单内容和顺序、弹层样式、留白、交互方式（点哪里出什么、悬停有没有反应）都和旧版一模一样，不自己增减。旧版指：
   - Web、桌面：旧 Vue 前端在同样窗口宽度下的样子
   - App：`resources/app` 的实际界面（已原生化的页面看原生页面，其余看 WebView 里的 Vue 手机版）

   只有两类地方可以和旧版不同，都要**先和用户商量**，定了写进第 10 节：
   - 旧设计本身不合理、不规范的地方
   - 为了一套代码兼容多端，在某一端显得别扭的地方（例：任务状态弹出菜单偏网页风格；仪表盘在 App 上偏小、间距不像 App）。Web 保留同类风格做视觉优化，App 按手机习惯调尺寸和间距，内容和结构不变
2. **一处定义，到处引用**。颜色、字号、间距、圆角集中定义，页面只引用，不写字面量（文件类型色、群头像底色这类语义色也集中定义）。头像、弹窗外壳这类反复出现的元素各只有一个实现。
3. **平台差异跟旧版走**。旧版各端本来就不一样的地方照各端旧版做；第 6 节列出的差异以旧版为准核对。
4. **每次交互都有反馈**：按下态、悬停态、触感、过渡动画至少有其一。
5. **先出骨架，再出数据**。能用已有数据（列表、缓存）画出来的就立即画，不允许出现只有转圈的白屏。

## 2. 字体

只用系统字体。字号单位 dp，跟随系统大字体（`allowFontScaling` 默认开启），只在角标、头像字母等固定尺寸元素上关闭。

| 令牌 | 字号 / 行高 / 字重 | 用途 |
|---|---|---|
| `title1` | 22 / 28 / 700 | 大标题（资料页姓名） |
| `title2` | 17 / 22 / 600 | 导航栏标题、弹窗标题 |
| `body` | 16 / 22 / 400 | 消息正文、输入框 |
| `callout` | 15 / 20 / 400 | 列表行主文字、按钮 |
| `subhead` | 14 / 19 / 400 | 列表行副文字、卡片正文 |
| `footnote` | 13 / 18 / 400 | 分组标题、说明 |
| `caption` | 12 / 16 / 400 | 时间、附加信息、系统消息 |
| `caption2` | 11 / 13 / 500 | 角标、气泡内时间 |

- 文字层级不超过 3 级：一级 `text`，二级 `text2`，三级 `text3`
- 代码用等宽字体（iOS Menlo，Android monospace，Web 系统等宽字体），14 / 20
- **单行输入框不设行高**：iOS 上设了行高，文字不垂直居中，长文字失焦后还会折行

## 3. 间距、圆角、尺寸

- 间距 4 的倍数：`xs 4`、`sm 8`、`md 12`、`lg 16`、`xl 20`、`xxl 24`；页面左右边距 `page 16`
- 圆角
  - 气泡 18（连续消息靠近一侧的角收为 6）
  - 卡片 12
  - 小块 / 输入框 10
  - 图片 12
  - 底部弹层顶部：iOS 14、Android 28、Web 14
  - 居中对话框：iOS 32、Android 28、Web 12
  - 胶囊 999
- 触控区域最小 44 × 44（iOS、Web）/ 48 × 48（Android），视觉更小的元素用 `hitSlop` 补足
- 导航栏高 52 + 顶部安全区，标题居中（Android 也居中）。页面都用应用自己的导航栏（`PageHeader`），不用系统导航栏：iOS 26 的系统导航栏是半透明的，会盖住内容
- 标题栏下面紧接的工具条（分类页签、筛选、搜索框、添加栏、查找条）属于导航区：标题和工具条之间不画线，整个顶部区域只在最下面一条分割线。内容一开头就是分组色带或大块资料区的页面，这条线也不要
- 列表行最小高 52（单行）/ 64（双行带头像）；行高在安卓非整数密度上对齐整像素，否则相邻行会盖住分割线
- 头像尺寸只用：20 / 24 / 32 / 40 / 48 / 64 / 80（`size.avatar` 的 xs–huge）；会话列表 48
- 未读角标最小宽高 18；分类胶囊高 30；列表顶部搜索框高 36
- 输入框、整行按钮高 48；登录类表单最大宽 360，宽屏居中
- 加号面板：最近照片缩略图 96（`photoThumb`），功能入口方块 56（`moreTile`）
- 贴底的内容（底部弹层、发送预览）让底边用 `bottomInset(rt.insets.bottom, rt.insets.ime)`：键盘弹出时让到键盘上沿。Android 上 unistyles 的 `ime` 已减去导航栏、iOS 是键盘全高，差异在这个函数里抹平；要直接传值，unistyles 靠字面上的 `rt.insets.ime` 识别依赖

## 4. 动效与触感

- 按下态：行用 `fillPressed` 背景，图标按钮透明度 0.5，主按钮 0.85；不可用 0.4
- 触感（只在 App 上）
  - `selection`：切换分段、勾选、选项
  - `light`：打开弹窗、长按菜单弹出
  - `success` / `error`：提交结果
- 底部弹层从底部弹入，可下拉关闭；回弹不过冲
- 列表定位高亮：目标行背景 `rowHighlight` 闪两次后淡出（共约 1.2 秒），不加全屏遮罩
- Web 上的进出场动画用 CSS 过渡，不占 JS 帧（见 performance.md）

## 5. 常用元素

| 元素 | 设计要求 |
|---|---|
| 头像 | 图片加载失败时回退为底色加首字或图标（规则见 1.5）；在线时右下角显示在线点 |
| 确认 | 是 / 否两选的确认按 architecture.md 第 7 节：App 用系统确认框，Web / 桌面是锚在按钮旁的气泡。确定按钮的颜色按后果选，见下面「对话框」 |
| 对话框 | 需要类型图标、三个以上按钮或要等结果的提示用自绘对话框，各端同一样式：宽 min(300, 屏宽 − 48) 居中，平板不拉宽；内边距上 24、左右 20、下 20；可选类型图标（44 圆形浅色底：错误 ×、警告三角、成功勾、提示 i）；标题 `title2` 居中，正文 `subhead` `text2` 居中（没有标题时正文 `body` `text`），过长可滚动；按钮为高 48 的胶囊，间距 10，不画分割线。**确定按钮的颜色按后果选**：删除、解散 / 退出 / 移出、撤回、放弃修改、清空、退出登录等丢数据或失去权限的用 `danger`；归档、重置、覆盖、还原版本、结束投票等影响大但可恢复的用 `warning`；其余用主色。两个按钮且放得下时横排（取消在左），三个以上或放不下时竖排铺满（操作在上、取消在最下）。按钮的 onPress 返回 Promise 时等结果：超过 150ms 才转圈、其他按钮变灰（免得立刻回来的结果闪一下），成功关闭，失败留着并提示错误。点遮罩不关，系统返回键 / Esc 等于「取消」。多层弹窗叠放时遮罩只有一层，返回键只关最上面一层 |
| 输入弹窗 | 底部弹层，左上取消、右上确认（危险操作红字、需要留意的操作橙字），打开即聚焦；单行灰底输入框带清除按钮，回车即确认；多行 3–6 行自动增高，回车换行，有字数上限时显示计数；数字输入弹数字键盘。确认时转圈，成功关闭、失败留着并提示错误 |
| 底部弹层 | 顶部有拖拽条，标题居中；有确认操作时左上「取消」、右上确认（如「发送」「完成」），只查看或点选即关的弹层右上角为圆形 ×；内容可滚动，留出安全区；里面的行通栏铺在弹层白底上，不套灰底圆角块；分组之间隔一条 8 高的 `bg` 色带，首尾不放；中屏、宽屏上改为居中弹窗或右侧抽屉（第 9 节） |
| 分组 | 设置、资料页、任务详情一致：通栏白底，组与组之间隔一条 8 高的 `bg` 色带，标题为组内首行加粗 16；表单的填写提示不是分组名，用 `footnote` + `text3`；页面第一块前面也放这条带，标题栏下不画线；不用圆角卡片 |
| 列表行 | 左侧图标或头像，主 / 副文字，右侧是值、开关、箭头之一；有按下态和悬停态；分隔线从文字左缘开始（iOS 式内缩）；分栏里被打开的那一行用 `rowHighlight` 标出 |
| 开关 | 用平台原生开关，统一配色（iOS 绿色轨道；Android Material 3） |
| 骨架屏 | 圆形 / 矩形块，带呼吸动画，用于首屏占位 |
| 长按菜单 | App 上被长按的气泡上浮，背景压暗；上方是表情条，下方是分组的紧凑菜单。Web / 桌面上是右键菜单（第 9 节） |
| 未读角标 | 红底白字胶囊，`caption2`，超过 999 显示 999+；免打扰的会话用 `badgeMuted`；底部 Tab、图标侧栏上浮在图标右上角，完整侧栏放在行尾 |
| 搜索框 | `fill` 底圆角胶囊，左侧放大镜，有字时右侧清除按钮；放在标题栏下的工具条里 |
| 轻提示 | 屏幕下方居中的深底白字胶囊，2.5 秒后自动消失，不挡操作；用于「已置顶」这类不需要确认的结果 |
| 多选勾选圈 | 用于转发目标、邀请成员：未选时 `text4` 描边圆圈，选中时品牌色实心加白勾 |

## 6. 平台差异

| 场景 | iOS | Android | Web / 桌面 |
|---|---|---|---|
| 开关 | UISwitch 外观 | Material 3 | 与 iOS 外观一致 |
| 底部弹层顶部圆角 | 14 | 28 | 14（只在窄屏） |
| 对话框圆角 | 32 | 28 | 12 |
| 菜单 | 系统菜单（UIMenu） | 系统弹出菜单 | 自绘菜单，支持子菜单 |
| 确认 | 系统确认框 | 系统确认框 | 锚在按钮旁的气泡 |
| 长按菜单 | 气泡上浮 + 遮罩 + 菜单 | 同 iOS | 右键菜单 |
| 返回 | 左滑返回 | 系统返回键 / 手势：先关浮层、退出多选，再退页面 | 浏览器后退；Esc 关浮层 |
| 触感 | Haptics | Haptics（系统未开启触感时静默） | 无 |
| 悬停 | 无 | 无 | 悬停底色、指针、悬停提示 |

> 背景模糊需要 `expo-blur`（原生依赖，当前没装）。装上之前长按菜单统一用半透明遮罩。

## 7. 文案

- 关闭类按钮用图标，不用「取消」文字；需要确认的弹窗用「完成」或具体动词（「发送 (3)」「创建」）
- 时间统一本地时区，分级显示：今天 `HH:mm`、昨天 `昨天 HH:mm`、本年 `M月D日`、跨年 `YYYY年M月D日`（各语言按 i18n 的日期格式）
- 不暴露内部字段（群组 ID 等放到底部「更多信息」或长按复制）
- 所有用户可见文字走 i18n 键

## 8. 验收方式

每批改完，在 Web（Playwright，窄 / 中 / 宽三档）和安卓模拟器上逐屏截图，**和旧版同一屏并排对比**：除第 10 节登记的调整外都要一致（布局、颜色、字号层级、间距、留白、菜单内容、悬停和按下的反应、深色模式）。iOS 由用户真机验收。

## 9. 宽屏与桌面

布局按窗口宽度分三档，不看设备类型（architecture.md 第 7 节）。

### 9.1 布局尺寸

| 元素 | 尺寸 |
|---|---|
| 窄屏底部 Tab 栏 | 高 56 + 底部安全区 |
| 中屏图标侧栏 | 宽 72 |
| 宽屏完整侧栏 | 宽 220，底色 `nav`（浅色 `#EBEDF0`、深色 `#111113`），比列表栏深一档 |
| 列表栏 | 中屏固定 320；宽屏默认 320，可拖动 260–480，拖动时光标为左右箭头，宽度记住 |
| 居中弹窗 | 宽 480 |

- 分栏时列表栏和详情区之间一条发丝线；列表栏里当前打开的那一行用 `rowHighlight` 标出
- 窄屏的底部弹层在中屏、宽屏上改为居中弹窗（默认）或右侧抽屉；点遮罩、Esc 关闭
- 详情区内容过宽时限宽居中，不让一行文字横跨整屏

### 9.2 悬停与焦点

- 可点的元素都有悬停态：叠一层 `hover`（浅色 `rgba(31,35,41,0.05)`、深色 `rgba(255,255,255,0.06)`），光标为手形
- 只有图标没有文字的按钮，悬停时显示悬停提示（全页共用一个提示层，最大宽 240）
- 键盘焦点：输入框聚焦时 1 像素 `focusRing` 描边；键盘移到按钮、菜单项上时有可见的焦点样式

### 9.3 菜单、气泡、提示

- 自绘菜单：行高 32，宽 180–320，`surface` 底、圆角 6、阴影 `popover`；左侧图标（可选）、右侧快捷键或子菜单箭头；方向键 + 回车选择，Esc 关闭
- 贴边时自动翻转到另一侧；右键菜单出现在鼠标位置
- 确认气泡最大宽 280、圆角 6，锚在按钮旁，按钮为「取消」+ 确定（颜色规则同对话框）
- 浮起的面板（菜单、气泡、弹窗）用同一组阴影：浅色 `0 8px 28px rgba(0,0,0,0.12)` + 1 像素描边阴影；深色加强阴影并用 1 像素浅色描边

### 9.4 文字和快捷键

- 界面文字（按钮、标签、列表标题）不能选中；内容文字（消息、任务描述）可以选中复制
- 常用操作提供快捷键，`mod` 在 Mac 上是 Command、其他系统是 Ctrl；菜单项右侧显示快捷键（Mac 上 `⇧⌘K`，其他系统 `Ctrl+Shift+K`）
- 能拖文件上传的区域，拖着文件进来时盖一层 `primarySoft` 底、`primary` 虚线框的蒙层，中间写可以松手做什么
